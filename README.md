# ProfileScout — Vercel-ready Test Build

Deploy:
1. Create a new Vercel project.
2. Upload/import this folder.
3. Add Environment Variable: SERPER_API_KEY = your Serper API key.
4. Deploy.

Works:
- Aranca branding
- JD input
- Live public LinkedIn profile discovery
- Valid linkedin.com/in URLs only
- Deduplication
- Recruiter checkboxes
- Selected-candidate review
- Work email entry
- Invitation preview containing original JD
- Simulated outreach

Portable: no Vercel, Supabase, or provider project IDs are hard-coded.
